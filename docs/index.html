A multilingual DSL (French, English, Spanish, German, Italian, Portuguese) that compiles entities, APIs, auth and pages into a FastAPI backend, a CSS-stylable Reflex UI, Docker images and Kubernetes/Helm manifests — all from a single text file.

En pratique

In practice

De l'intention au code, en quelques lignes

From intent to code, in a few lines

boutique.nova
entité Produit {
  champ nom: chaine requis
  champ prix: decimal requis
  champ email_contact: chaine motif = "^[^@]+@[^@]+$"
}

api Produit {
  liste
  créer
  modifier
  supprimer
}

page Catalogue {
  afficher Produit comme table titre "Catalogue"
}

What this file generates

  • A SQLModel Produit model with regex validation on email_contact
  • Des routes CRUD FastAPI complètes, documentées dans Swagger
  • Full CRUD FastAPI routes, documented in Swagger
  • Une page Reflex avec tableau, navbar et lien vers un formulaire de création
  • A Reflex page with a table, navbar, and a link to a creation form
  • Un Dockerfile par service et un chart Helm prêt à adapter
  • A Dockerfile per service and a Helm chart ready to adapt
